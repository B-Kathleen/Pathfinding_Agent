This pathfinding AI agent was developed to solve a maze game in a competitive environment against a human player. Built using TensorFlow and the Keras API, the agent implements a Deep Q-Network (DQN) architecture, utilizing a sequential neural network to approximate action-value (Q-value) predictions. The agent employs Deep Reinforcement Learning, specifically Q-learning and implements the epsilon-greedy action selection strategy, allowing the agent to learn and predict its most optimal path while retaining a minimum exploratory rate. 

The neural network consists of two hidden Dense layers with PReLU activation functions and an output layer corresponding to the available actions. The model was trained over 15,000 episodes, progressively refining its action-value predictions through reward-based learning. By the conclusion of training, the agent achieved a 100% success rate in completing its objective.
